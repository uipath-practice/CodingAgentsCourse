# Getting Started with Coding Agents

**Set up the UiPath CLI and skills, then drive UiPath from your coding agent.**

## Overview

A **coding agent** like **Claude Code** can build and operate UiPath automations the same way a developer does — once it knows how. You teach it with two things: the **UiPath CLI** (`uip`), the command-line interface agents use to talk to the platform, and **UiPath skills**, curated instruction packs that tell the agent *when* and *how* to use that CLI.

This first exercise gets your environment ready and gives you a feel for the CLI before you build anything. By the end you'll have a coding agent that recognizes UiPath tasks and proposes the right commands on its own.
